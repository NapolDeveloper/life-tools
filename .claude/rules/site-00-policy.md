# life-tools(돈셈) 사이트 정책

> 상위: common-00-policy.md (충돌 시 공통 우선)

## 1. 광고
- 첫 광고 위치: 도구 페이지의 '결과 상세' 블록 아래부터.
- 승인 후 페이지당 2~3개.

## 2. 콘텐츠 기준
- 도구 페이지마다 계산기 외 설명글 1,200자 이상(사용법·계산 근거·예시·FAQ 합산).
- 애드센스 신청 시점: 도구 10개 + 필수 페이지 완성 후.

## 3. 계산 정확성·면책
- **출처:** 요율·법정 기준값은 정부·공공기관 원문만(국세청, 국민연금공단, 국민건강보험공단, 고용노동부, 국가법령정보센터 등). 언론·블로그는 변경 소식 파악용 참고만.
- **데이터 관리:** 기준값은 `src/data/`에 상수로, 값마다 기준 연도·적용 기간·출처 URL·확인일 주석.
- **검증:** ① 단위 테스트 ② 공식 계산기와 같은 입력 3건 이상 대조 → `docs/verification/{도구}.md` 기록. 차이가 있으면 원인을 '계산 방식'에 설명.
- **갱신:** 매년 1월·7월 정기 점검 + 개정 확인 시 수시 반영. 반영 시 최종 갱신일 변경.
- **오류 신고:** 48시간 내 확인, 수정 시 페이지 하단 '변경 이력'에 날짜·내용 기록.
- **면책:** 결과 바로 아래 "참고용, 실제와 다를 수 있음" + 하단 상세 안내(공식 기관 확인 권장). 세무·법률 자문처럼 보이는 표현 금지.

## 4. 리소스 선택
- 글꼴: Pretendard 웹폰트 1종(SIL OFL), 서브셋·`font-display: swap`.
- 아이콘: Lucide(ISC), 필요한 아이콘만 SVG로 포함.
- 마스코트: 뒤죽덕죽 캐릭터 확정 후 마스코트로 재검토(현재 사용 안 함).
