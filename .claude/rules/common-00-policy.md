# 공통 필수 정책 (모든 애드센스 웹사이트)

> 적용 범위: 이 사용자가 운영하는 **모든** 애드센스 수익형 웹사이트. 충돌 시 이 문서가 우선.

## 1. 광고 배치·클릭
- **승인 전:** 광고 0개. 운영 빌드에 빈 광고 슬롯도 노출하지 않는다.
- **승인 후 개수:** 페이지당 2~3개 이내에서 단계적으로 추가(사이트별 문서에서 세부 지정).
- **방식:** 수동 광고 단위만. 자동 광고·앵커·전면 광고 사용 안 함.
- **위치:** 입력칸·버튼·핵심 결과/콘텐츠 사이와 바로 옆 금지. 첫 광고는 사용자가 원하는 핵심 정보를 얻은 이후 위치(사이트별 문서에서 블록 지정).
- **미리보기·개발 환경:** 광고 코드 미삽입, 회색 빈 자리만 표시.
- **금지:** 본인 광고 클릭, 클릭 유도 문구, 광고를 콘텐츠·버튼처럼 보이게 하는 디자인, 광고를 가리키는 화살표·이미지.
- 광고 위 "광고" 라벨, 슬롯 높이 미리 확보(CLS 방지).

## 2. 콘텐츠 품질
- **AI 작성:** 가능. 단 ① 사실·수치·법령은 공식 원문과 대조하고 출처를 남긴다 ② 사용자가 미리보기에서 훑어본 뒤 운영 반영.
- **대량 페이지:** 키워드·숫자만 바꾼 템플릿 페이지 대량 생성 금지. 예외는 사용자 승인 + 페이지마다 고유한 내용이 있을 때만.
- **복제 금지:** 다른 사이트 문장·표·구조 복제 금지. 독자적 설명·예시로 작성.
- **애드센스 신청 조건(공통 최소):** 커스텀 도메인 연결 + 필수 페이지(소개·개인정보처리방침·이용약관·문의) + 사이트별 문서에서 정한 콘텐츠 수량 충족.

## 3. 개인정보·쿠키
- **통계:** GA4. 운영 빌드에서만 로드, 미리보기·개발 환경 제외.
- **EU·영국·스위스 방문자:** 애드센스 내장 구글 동의 메시지 사용(승인 후 사용자 계정에서 설정).
- **국내 방문자:** 쿠키 배너 없음. 개인정보처리방침에 GA4·애드센스 쿠키, 맞춤형 광고, 거부 방법(브라우저 설정·구글 광고 설정 링크) 명시.
- **문의:** 이메일 주소만 공개. 사이트 자체 개인정보 수집(폼·회원가입) 없음.
- **사용자 입력:** 브라우저에서만 처리, 서버 전송·저장 없음. 처리방침에 명시. URL 쿼리에 이름·연락처 등 식별 정보를 담지 않는다.

## 4. 저작권·라이선스
- **이미지:** 코드로 직접 생성한 것만(도형·텍스트 기반 OG 이미지·삽화). 외부 사진·스톡·AI 생성 이미지 사용 안 함.
- **외부 리소스:** 글꼴·아이콘·라이브러리는 상업 이용 가능한 오픈 라이선스만. `docs/licenses.md`에 이름·라이선스·출처 기록, 필요한 경우 라이선스 사본 포함.
- **텍스트:** 법령·고시 원문 인용은 짧게, 출처 표기.
- **상표:** 타 기업·서비스 상표명을 사이트명·도구명·도메인에 쓰지 않는다. 사이트명은 확정 전 KIPRIS 동일·유사 상표 조사.
- **자체 캐릭터(뒤죽덕죽):** 이름·디자인 확정과 권리 검토 전까지 웹사이트에 사용하지 않는다.

## 5. 접근성
- WCAG 2.x AA 수준.
  - 색 대비: 본문 4.5:1, 큰 글자·아이콘·입력 테두리 3:1 이상.
  - 모든 기능을 키보드만으로 사용 가능, 초점 표시(`:focus-visible`) 유지.
  - 모든 입력에 `<label>`, 오류 메시지는 `aria-describedby`로 연결.
  - 동적으로 바뀌는 핵심 결과는 `aria-live="polite"`로 알림.
  - 색만으로 의미 전달 금지, `prefers-reduced-motion` 존중, 200% 확대 시에도 사용 가능.
- Lighthouse Accessibility 90+.
