# life-tools(돈셈) 사용성

## 0. 원칙
들어오자마자 숫자 하나 넣고 답을 본다. 설명·광고·FAQ는 그다음. 사용자 가정: 모바일 다수, 검색으로 도구 페이지에 바로 착지, 한 번 쓰고 나감.

## 1. 입력·결과 기본 동작
- **계산 시점:** 입력이 바뀌는 즉시 자동 계산(디바운스 약 150ms). "계산하기" 버튼은 키보드·스크린리더용 보조.
- **기본값:** 가장 흔한 값을 미리 채우고 결과도 미리 표시(예: 연봉 4,000만원, 식대 20만원, 부양가족 1명). 기본값 결과는 빌드 시 HTML에 렌더링해 JS 없이도 보이게.
- **공유:** ① 결과 복사("월 실수령액 2,924,353원 (연봉 4,000만원 기준, 돈셈)" 형태, 성공 토스트 2초) ② 공유 링크 — 입력값을 URL 쿼리에 반영(history.replaceState), 이 링크로 열면 같은 결과. Web Share API 우선, 미지원 시 링크 복사. canonical은 쿼리 없는 주소.

## 2. 입력 세부
- 금액: `type="text"` + `inputmode="numeric"`, 천 단위 콤마 자동, 단위(원·만원) 고정 표시, 아래에 한글 읽기("4,000만 원"). `type="number"` 스피너 금지.
- 빠른 입력 칩(예: +100만, +1,000만).
- 정수 개수(가족 수 등)는 −/+ 스테퍼. 선택지 2~4개는 세그먼트, 5개 이상만 select.
- 헷갈리는 필드는 아래 회색 힌트 한 줄. 선택 항목은 "상세 옵션" 접기 안에.
- 입력 순서: 사람이 확실히 아는 값 → 덜 확실한 값.

## 3. 결과 세부
- 핵심 숫자 1개를 가장 크게(결과 카드), 보조 숫자 1~2개.
- 숫자 변경 시 0.3초 하이라이트(`prefers-reduced-motion`이면 생략).
- 내역 표: 항목 / 금액 / 비율, 합계 행 강조. "YYYY년 기준" 표시.
- 비정상 입력은 결과 영역에 이유를 쓴다("연봉은 0보다 커야 해요"). NaN·빈칸 노출 금지.

## 4. 모바일·레이아웃
- 360px 기준 설계, 가로 스크롤 금지(표는 스크롤 래퍼 안에서만).
- 768px 이상: 계산기 입력 | 결과 2단 가능.
- 모바일에서 입력 중 결과가 화면 밖이면 하단 고정 미니 결과바(핵심 숫자만).
- 키보드가 올라와도 현재 입력칸이 가려지지 않게. 불필요한 강제 스크롤 금지.

## 5. 성능 체감
- 도구 페이지 JS 합계 30KB(gzip) 이하, UI 라이브러리 금지. JS는 인터랙션용으로만.

## 6. 신뢰
- 요율·공식·출처·기준일을 '계산 방식' 블록에 명시. 최종 갱신일 표시.
- "참고용" 안내는 결과 바로 아래 한 줄 + 하단 상세.

## 7. 문구 톤
- 해요체, 친근하고 짧게. 예: "연봉을 넣으면 매달 받는 돈을 알려드려요."
- 전문용어는 처음 한 번 풀어서("비과세액: 세금이 안 붙는 돈, 예: 식대").
- 버튼은 동사형: "복사하기", "링크 공유", "초기화".
- 숫자: 천 단위 콤마 + "원", 큰 금액은 "만 원" 병기. 과장 표현 금지("가장 정확한", "100%").

## 8. 도구 추가 체크리스트
- [ ] 360×640 첫 화면에 입력칸과 결과가 보임
- [ ] 기본값 결과가 JS 없이 보임
- [ ] 실시간 계산·콤마·한글 읽기·단위
- [ ] 복사·공유 링크 동작, 공유 URL로 열면 같은 결과
- [ ] 오류 입력 시 이유 표시, NaN 없음
- [ ] 키보드만으로 사용 가능, aria-live 동작
- [ ] 광고가 입력/결과 사이에 없음
- [ ] 근거·출처·기준일·참고용 안내
- [ ] 관련 도구 3~4개 연결
