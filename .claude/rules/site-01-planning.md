# life-tools(돈셈) 서비스 기획

## 1. 도구 선정 기준
- **수요 확인:** 네이버 검색광고 키워드도구 월 검색량(PC+모바일). 사용자가 조회, Claude는 후보 키워드 목록을 준비하고 결과를 기록.
  - 기록: `docs/keywords.md` — 도구 | 메인 키워드 | 보조 키워드 3~5개 | 월 검색량(조회일) | 상위 경쟁 사이트 3개 | 시즌성.
- **주제:** 첫 도구 10개는 급여·세금·노동 분야 집중(후보: 연봉 실수령액, 퇴직금, 시급·주휴수당, 연말정산, 실업급여, 연차, 4대보험 등 — 수요 확인 후 확정).
- **순서:** 시즌 타이밍 + 검색량. 수요가 몰리는 시기 4~6주 전에 완성(예: 연말정산 → 12월 중순까지).
- 메인 키워드 1개 = 페이지 1개. 같은 의도의 페이지 중복 금지.

## 2. 도구 페이지 표준 구조 (위에서 아래 순서 고정)
| 순서 | 블록 | 비고 |
|---|---|---|
| 1 | Breadcrumb | 홈 > 카테고리 > 도구 |
| 2 | H1 + 한 줄 설명 | "무엇을 넣으면 무엇이 나오는지" 1문장 |
| 3 | 계산기 (입력 + 핵심 결과) | 모바일 첫 화면에 첫 입력칸과 결과 일부가 보이게 |
| 4 | 결과 상세 | 항목별 내역, 기준 연도, 복사·공유, "참고용" 한 줄 |
| 5 | 광고 ① | 승인 후. 결과 상세 아래가 첫 광고 위치 |
| 6 | 사용법 | 3~5단계 |
| 7 | 계산 방식·근거 | 공식, 요율 표, 출처, 기준일 |
| 8 | 예시 | 대표 입력 2~3개 결과 표 |
| 9 | 광고 ② | 승인 후 |
| 10 | 자주 묻는 질문 | 4~6개 |
| 11 | 관련 도구 | 같은 카테고리 3~4개 |
| 12 | 안내·변경 이력 | 면책 상세, 최종 갱신일, 변경 이력 |

## 3. 카테고리 구조
| 카테고리 | 허브 URL | 포함 도구(예) |
|---|---|---|
| 급여 | `/pay/` | 연봉 실수령액, 시급·주휴수당, 4대보험 |
| 세금 | `/tax/` | 연말정산, 종합소득세, 퇴직소득세 |
| 노동·고용 | `/work/` | 퇴직금, 실업급여, 연차 |
- 도구 URL은 평평하게(`/salary/`), 카테고리는 허브 페이지·Breadcrumb·헤더 내비로 연결.
- 허브 페이지: 카테고리 소개 2~3문단 + 도구 카드 목록.
