# 연말정산 계산기 검증 기록

대상: `/year-end-tax/` (`src/lib/year-end-tax.ts`, 기준값 `src/data/year-end-tax-2026.ts`, 기준 연도 2026년 귀속)
정책: site-00 §3 — 단위 테스트 + 공식 계산기와 같은 입력 3건 이상 대조. 차이가 있으면 원인을 페이지의 '계산 방식'에 설명한다.
작성: 2026-11-18. 근로소득공제·기본세율·근로소득세액공제·4대보험 요율은 `src/data/payroll.ts`(연봉 실수령액 계산기와 공유)를 그대로 쓴다.

## 1. 단위 테스트

`npm test` (`src/lib/year-end-tax.test.ts`, `src/lib/year-end-query.test.ts`)로 다음을 검증한다. 마지막 실행: 2026-11-18 통과.
- 근로소득공제 구간 경계(총급여 500만·1,500만·4,500만·1억, 상한 2,000만), 근로소득세액공제 한도 경계(3,300만·7,000만·1.2억)와 산출세액 130만 경계
- 카드 소득공제: 최저사용금액 차감 순서, 기본한도(7,000만 기준)·자녀 가산·추가한도, 7,000만 초과 시 문화 지출 처리
- 의료비 3% 문턱 차감 순서와 그 외 가족 700만 한도
- 연금계좌·월세·주택청약·기부금·교육비 한도, 출산·자녀·결혼 공제
- 표준세액공제 자동 선택, 결정세액 0 하한(환급), 기납부 추정과 직접 입력, 입력 보정·NaN 방지
- 예시 3건 결과 고정, 공유 링크 쿼리 왕복

### 계산 구조상 가정 (스펙과 별개로 확인 필요)
- 사회보험료(국민연금·건강·고용) 소득공제와 주택청약 소득공제는 표준세액공제를 고른 경우에도 그대로 적용한다.
- 표준세액공제와 항목별 공제의 결정세액이 같으면 표준세액공제를 고른 것으로 표시한다.
- 총급여 7,000만 원 초과 시 '문화' 입력액은 신용카드 사용액(공제율 15%)으로 합산한다. 실제 결제 수단별 공제율과 다를 수 있다.
- 기부금은 소득금액 한도를 적용하지 않는다. 교육비·월세·보험료의 세부 요건(소득 요건, 국민주택규모 등)은 입력자가 충족한다고 가정한다.
- 자녀 카드 한도 가산은 `만 9세 이상 자녀` + `만 8세 이하 자녀` 입력의 합계 인원으로 계산한다(스펙의 '기본공제 자녀 수'를 두 입력으로 나눈 것).
