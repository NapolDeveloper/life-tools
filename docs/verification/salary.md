# 연봉 실수령액 계산기 검증 기록

대상: `/salary/` (`src/lib/salary.ts`, 요율 `src/data/payroll.ts`, 기준 연도 2026)
정책: site-00 §3 — 단위 테스트 + 공식 계산기와 같은 입력 3건 이상 대조. 차이가 있으면 원인을 페이지의 '계산 방식'에 설명한다.

## 1. 단위 테스트

`npm test` (`src/lib/salary.test.ts` 등)로 4대보험 항목별 값, 합계 정합성, 국민연금 상한, 0원 입력, 음수 방지를 검증한다. 마지막 실행: 2026-11-18 통과.

## 2. 공식 계산기 대조

대조 대상 공식 계산기(예: 국세청 근로소득 간이세액표 조회, 국민연금공단·건강보험공단 보험료 모의계산)에 아래 입력을 똑같이 넣고 결과를 기록한다.
공통 가정: 월급은 연봉 ÷ 12(원 미만 버림), 비과세는 식대 월 20만 원, 상여금 없음, 2026년 요율.
**"공식 결과"와 "차이" 칸은 사용자/메인 세션이 채운다. 아래 "미확인"은 아직 대조하지 않았다는 뜻이다.**

## 3. 차이 원인 정리 (대조 후 작성)

- 소득세: 돈셈은 간이세액표가 아니라 소득세법 구조로 근사 계산한다(페이지 '계산 방식'에 설명 중). 차이가 크면 간이세액표 구간값 반영 여부를 검토한다.
- 4대보험: 차이가 나면 기준소득월액 상·하한, 10원 미만 절사 방식, 요율을 먼저 확인한다.
- 차이 원인이 확인되면 `/salary/`의 '계산 방식' 블록과 이 문서를 함께 고치고, 페이지 '변경 이력'에 기록한다.

## 4. 수치 재현

위 "돈셈 결과"는 `calculateSalary()`를 입력값으로 직접 호출해 얻은 값이다(2026-11-18, 로직·요율 변경 없음).
