- 작성: 2026-11-18, 메인 세션(기획·기준 정리). 구현: Sonnet.
- URL: `/year-end-tax/` · 카테고리: 세금(`/tax/`) · 범위: **표준**(자주 쓰는 공제 8~10개)
- 메인 키워드: 연말정산 계산기 / 보조: 연말정산 환급금 계산, 2026 연말정산, 13월의 월급 계산, 연말정산 미리 계산

## 1. 계산 흐름
```
총급여(연봉 − 비과세)
 − 근로소득공제                         = 근로소득금액
 − 인적공제(기본 150만 × 인원 + 추가공제)
 − 연금보험료공제(국민연금 본인부담 전액)
 − 특별소득공제(건강·장기요양·고용보험 본인부담 전액, 주택청약*)
 − 신용카드 등 소득공제                 = 과세표준
 × 기본세율(누진)                       = 산출세액
 − 세액공제 [근로소득·자녀·연금계좌·특별(보험·의료·교육·기부)·월세·결혼 또는 표준]
                                         = 결정세액 (0 미만이면 0)
 결정세액 × 10% = 지방소득세
 (결정세액 + 지방소득세) − (기납부 소득세 + 지방소득세) = 추가납부(+) / 환급(−)
```
*주택청약종합저축은 조특법상 소득공제(조특법 §87). 계산 순서상 신용카드 공제와 함께 차감.

- 4대보험 본인부담액은 기존 `src/lib/salary.ts`·`src/data/payroll.ts`의 요율로 **연간 추정치**를 기본값으로 계산하고, 사용자가 실제 금액으로 덮어쓸 수 있게 한다.
- 기납부세액: 입력값(원천징수영수증·급여명세서의 소득세 합계). 비워두면 `salary.ts`의 간이세액 근사로 연간 추정하고 "추정치" 표시.

## 2. 기준값 (2026년 귀속)
> 출처 표기 원칙: 정부·공공기관 원문만(site-00 §3). 아래 [확인]은 정책브리핑(정부 공식)에서 확인한 값, [검증 필요]는 기존 연도 기준값으로 법령 원문 대조가 필요한 값 — `docs/verification/year-end-tax.md`에 목록화하고 페이지 '계산 방식'에는 출처 링크만 둔다.

### 2-1. 근로소득공제 (소득세법 §47) [검증 필요 — 2014년 이후 변동 없음으로 알려짐]
| 총급여 | 공제액 |
|---|---|
| 500만원 이하 | 총급여 × 70% |
| 500만~1,500만 | 350만 + 500만 초과분 × 40% |
| 1,500만~4,500만 | 750만 + 1,500만 초과분 × 15% |
| 4,500만~1억 | 1,200만 + 4,500만 초과분 × 5% |
| 1억 초과 | 1,475만 + 1억 초과분 × 2% |
| 한도 | 2,000만 |

### 2-2. 기본세율 (소득세법 §55) — `payroll.ts`의 기존 상수 재사용

### 2-3. 인적공제 (§50·§51) [검증 필요]
- 기본공제 1인당 150만(본인 포함, 부양가족 요건은 안내 문구로).
- 추가공제(표준 범위): 70세 이상 1인당 100만, 장애인 1인당 200만. (부녀자·한부모는 범위 밖 → FAQ에서 언급)

### 2-4. 신용카드 등 소득공제 (조특법 §126의2)
- 최저사용금액: 총급여 × 25% [검증 필요]
- 공제율: 신용카드 15% / 체크카드·현금영수증 30% / 도서·공연·박물관·미술관·영화·(2025.7.1~)수영장·체력단련장 30%(총급여 7,000만 이하만) / 전통시장 40% / 대중교통 40% [검증 필요]
- 최저사용금액은 공제율 낮은 순서(신용카드 → 체크·현금 → 문화 → 전통시장·대중교통)로 먼저 차감 [검증 필요 — 국세청 계산 방식]
- **기본한도 [확인: 정책브리핑 2025-10-30, 2026-01-06 — 자녀 1인당 +50만(최대 +100만), 7,000만 초과는 +25만(최대 +50만), 2028.12.31까지]**
  | 총급여 | 자녀 0 | 자녀 1 | 자녀 2+ |
  |---|---|---|---|
  | 7,000만 이하 | 300만 | 350만 | 400만 |
  | 7,000만 초과 | 250만 | 275만 | 300만 |
  - 자녀 요건: 기본공제 대상 자녀(직계비속) — 입력은 "기본공제 받는 자녀 수"를 재사용.
- 추가한도 [검증 필요]: 7,000만 이하 — 전통시장·대중교통·문화 합산 최대 300만 / 7,000만 초과 — 전통시장·대중교통 합산 최대 200만.
- 소비증가분 추가공제(전년 대비)는 **범위 밖**(FAQ에 언급).

### 2-5. 주택청약종합저축 소득공제 (조특법 §87) [검증 필요]
- 총급여 7,000만 이하 무주택 세대주(2025년 귀속부터 배우자 포함). 납입액 연 300만 한도 × 40% (최대 120만).

### 2-6. 근로소득세액공제 (소득세법 §59) [검증 필요]
- 산출세액 130만 이하: × 55% / 초과: 71.5만 + 130만 초과분 × 30%
- 한도: 총급여 3,300만 이하 74만 / 3,300만~7,000만: max(74만 − (총급여−3,300만)×0.008, 66만) / 7,000만~1.2억: max(66만 − (총급여−7,000만)×1/2, 50만) / 1.2억 초과: max(50만 − (총급여−1.2억)×1/2, 20만)

### 2-7. 자녀세액공제 (§59의2)
- 금액 [확인: 2025년 귀속부터 상향 — 1명 25만, 2명 55만, 3명 이상 55만 + 2명 초과 1명당 40만]
- 대상 나이: **2026년 귀속 9세 이상**(단계적 상향, 13세까지) [검증 필요 — 부칙 경과규정. 2017년생 처리 포함]. 입력 라벨에 "만 9세 이상 ~ 20세 이하 기본공제 자녀"로 명시하고 FAQ에 나이 기준 설명.
- 출산·입양 공제(첫째 30만/둘째 50만/셋째 이상 70만) [검증 필요] — "올해 태어나거나 입양한 자녀" 선택 입력(0~3).

### 2-8. 연금계좌 세액공제 (§59의3) [검증 필요]
- 연금저축 연 600만 한도, IRP 포함 합산 900만 한도.
- 공제율: 종합소득 4,500만 이하(근로소득만이면 총급여 5,500만 이하) 15%, 초과 12%.

### 2-9. 특별세액공제 (§59의4)
- 보험료(보장성): 12%, 100만 한도 [검증 필요]
- 의료비: 총급여 3% 초과분 × 15%. 본인·65세 이상·장애인·6세 이하 한도 없음, 그 외 가족 700만 한도. 3% 미달액은 '그 외 가족' 의료비에서 먼저 차감 [검증 필요]
- 교육비: 15%. 본인 한도 없음, 취학 전·초중고 1인당 300만, 대학생 1인당 900만 [검증 필요]. **2026년부터 초등 1~2학년(만 9세 미만) 예체능 학원비 포함 [확인: 정책브리핑 2026-01-06]**, 대학생 자녀 소득요건 폐지 [확인].
- 기부금: 15%(1,000만 초과분 30%) [검증 필요]. 고향사랑기부금 등 특례는 범위 밖.

### 2-10. 월세 세액공제 (조특법 §95의2) [검증 필요]
- 무주택 세대주, 총급여 8,000만 이하. 총급여 5,500만 이하 17%, 초과 15%. 연 1,000만 한도.
- 2026년부터 무주택 주말부부 각각 공제 가능, 부부 합산 1,000만 한도 [확인: 정책브리핑 2026-01-06] → FAQ 안내.

### 2-11. 결혼세액공제 (조특법 §92) [검증 필요]
- 2024~2026년 혼인신고 시 1회 50만. 체크박스 "2026년에 혼인신고를 했어요".

### 2-12. 표준세액공제 (§59의4⑨) [검증 필요]
- 13만. 특별소득공제·특별세액공제·월세세액공제를 신청하지 않은 경우 적용 → 계산기는 **(항목별 공제 경로)와 (표준세액공제 경로)를 모두 계산해 유리한 쪽 자동 선택**, 결과에 어느 쪽인지 표시.

### 2-13. 기타
- 세액공제 합계는 산출세액을 넘을 수 없음(결정세액 하한 0). 근로소득세액공제·자녀세액공제 등 순서 적용 시 결정세액이 음수가 되지 않게.
- 지방소득세 = 결정세액 × 10% (원 단위 절사 규칙은 기존 salary 모듈과 동일).

## 3. 입력 UX (site-02 준수)
- **첫 화면:** 연봉(MoneyInput, 기본 4,000만) → 결과 카드(ResultHero: "예상 환급액" 또는 "예상 추가 납부액", 색은 의미 토큰 — 환급 primary, 추가납부 danger 아님(불안 조장 방지) → `text` + 아이콘·문구로 구분, 색만으로 구분 금지).
- 결과 카드 아래 '조건 바꾸기' 영역, 그룹별 접기(Details):
  1. 기본 정보: 비과세액(월), 부양가족 수(본인 포함, Stepper), 70세 이상·장애인 인원, 기본공제 자녀 수(9세 이상), 올해 출생·입양 자녀
  2. 이미 낸 세금: 기납부 소득세(비우면 추정, 안내 문구)
  3. 카드 사용액: 신용카드 / 체크·현금영수증 / 문화 / 전통시장 / 대중교통 (연간)
  4. 의료비·교육비·보험료·기부금
  5. 연금저축·IRP, 주택청약
  6. 월세, 결혼(체크박스)
- 기본값: 연봉 4,000만, 부양가족 1, 카드 신용 1,200만·체크 400만·대중교통 60만, 나머지 0 — 결과는 빌드 시 HTML 렌더링.
- **결과 상세:** 단계별 표(총급여 → 근로소득금액 → 과세표준 → 산출세액 → 세액공제 내역 → 결정세액 → 기납부 → 차액), 카드 공제 상세(최저사용금액·항목별 공제·한도 적용), 표준세액공제 선택 여부.
- **절세 힌트(정보성, 과장 금지):** 결과 상세 아래 2~3개 — "카드 공제 한도까지 남은 금액", "연금저축 공제 한도까지 남은 납입액" 같은 계산된 사실만. 권유·확정 표현 금지.
- 공유 링크: 입력값 쿼리 반영(금액만, 식별정보 없음).
- 면책: 결과 바로 아래 "참고용 계산이에요. 실제 정산은 회사·국세청 기준으로 확정돼요." + 하단에 홈택스 '연말정산 미리보기' 안내(링크).

## 4. 페이지 콘텐츠 (site-01 §2 구조, 해요체, 1,200자 이상)
- 사용법: 원천징수영수증·홈택스 간소화 자료로 숫자 찾는 법 3~5단계.
- 계산 방식: §1 흐름 요약 + 주요 기준표 + 2026년 달라진 점(카드 한도 자녀별 상향, 초등 1~2학년 예체능 학원비, 자녀세액공제 나이 9세 이상, 주말부부 월세) + 출처 링크.
- 예시: 연봉 3,000만·자녀 0 / 5,000만·자녀 2·카드 많이 / 7,000만·연금저축 600만 3가지 결과 표.
- FAQ 5~6개: 환급/추가납부 차이, 기납부세액 찾는 곳, 표준세액공제가 뭔지, 자녀세액공제 나이 기준, 범위 밖 항목(부녀자·한부모·소비증가분·고향사랑기부금 등), 계산이 회사 결과와 다른 이유.
- 관련 도구: 연봉 실수령액 계산기 + 준비 중 세금 도구 텍스트.
- 출처(공공기관만): 국가법령정보센터 소득세법·조세특례제한법, 국세청 연말정산 종합안내(https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2304&cntntsId=238938), 정책브리핑 2025-10-30(https://www.korea.kr/news/policyNewsView.do?newsId=148953499), 2026-01-06(https://www.korea.kr/news/policyNewsView.do?newsId=148957544).

## 5. 검증 (site-00 §3)
- 단위 테스트: 구간 경계(총급여 500만/1,500만/4,500만/1억, 세액공제 한도 3,300만/7,000만/1.2억, 산출세액 130만), 카드 공제 최저사용금액 차감 순서·기본/추가한도·자녀 한도, 의료비 3% 차감 순서, 표준세액공제 자동 선택, 결정세액 0 하한.
